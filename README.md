## نسخه ۵.۸

### صفحه امروز (لندینگ)
- جلسات امروز، بدهکاران، خلاصه آماری
- اقدام سریع: انجام / لغو / پیامک / واتساپ
- هدر هماهنگ با تم انتخابی (بدون رنگ قرمز ثابت)

### یادآوری
- AlarmManager دقیق (۱ روز و ۱ ساعت قبل)
- اعلان اکشن‌دار: تأیید، لغو، تماس
- قالب پیام قابل ویرایش

### مالی و پرونده
- مبلغ، وضعیت پرداخت، روش پرداخت، سریال فاکتور
- یادداشت جلسه + فیلدهای SOAP + تگ موضوعی
- گزارش ماهانه/سالانه

### آزمون‌ها و کارگاه
- بانک آزمون‌های غربالگری (PHQ-9، DASS-21 و ده‌ها مورد دیگر)
- مدیریت کارگاه و شرکت‌کنندگان + خروجی اکسل

### پشتیبان‌گیری کامل
- خروجی JSON شامل: مراجعین، نوبت‌ها، یادداشت‌ها، پرسشنامه‌ها، کارگاه‌ها، تنظیمات
- **ذخیره روی گوشی** (پوشه backups اپ)
- **ارسال با جیمیل / گوگل درایو** و هر اپ اشتراک فایل
- بازیابی از متن JSON
- پشتیبان خودکار هفتگی در پس‌زمینه

### سایر
- Onboarding + داده نمونه
- قفل پین + بیومتریک
- برندینگ مطب (نام، تلفن، آدرس)
- تم‌های رنگی: آبی آسمان، رز سرخ، زمردی، بنفش، غروب
- ویجت نوبت بعدی
- Room + SQLCipher · Migration تا نسخه ۶
